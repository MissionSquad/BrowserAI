VoicePipeline is a headless press-to-talk state machine: mic → transcribe → LLM → spoken reply. With Kokoro in the speech slot, the reply is spoken sentence-by-sentence while the model is still generating. You build the UI from its typed events; this page is one such UI.

Models

Recommended chain ≈ 2.5 GB VRAM: Whisper Base + Qwen3.5 0.8B + Kokoro 82M. First load downloads them.

Conversation idle

Press once to start listening, press again to send. Pressing while a reply is playing stops it (barge-in). Discarded takes (too short, no speech, empty reply, or contention with other work) never touch the conversation history.
