@missionsquad/browserai — examples

Small AI models running entirely in your browser with WebGPU — no server. Each page is a self-contained demo of one part of the SDK. Models download on first use (hundreds of MB to a few GB) and are cached by the browser afterwards.

1 · Text generation

Load a text model, stream a completion token by token, and read the runtime metrics.

2 · Structured JSON

Schema-constrained decoding: extract a typed JSON object from free text and validate it.

3 · Speech in & out

Record the mic and transcribe it (STT); type text and synthesize speech (TTS).

4 · Voice assistant

The full press-to-talk pipeline: mic → transcribe → LLM → spoken reply, as events.

5 · Vision Q&A

Load a vision-language model and ask questions about an image you choose.

Requires a WebGPU-capable browser (recent Chrome, Edge, or Chrome-based). Transcription and speech models can fall back to wasm; text, vision, and multimodal models require WebGPU.
